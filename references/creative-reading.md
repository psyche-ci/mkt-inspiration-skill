# 固定版式读创意

用于用户主动粘贴链接、正文、截图 OCR 文本或案例材料时，把单条创意读成可收藏、可检索、可复用的结构化笔记。也用于每日抓取页中用户点击“AI 读创意”或“收藏进灵感库”的案例。

## 输入处理

1. 用户提供 URL 时，先尝试打开页面并核验标题、品牌、发布时间、发布主体、正文、图片/视频描述和原始链接。
2. 支持数英、SocialBeta、Ads of the World、品牌官网、公众号文章、Instagram、YouTube、B站、小红书等来源。能直接读就直接读；读不了就标注“需要登录/无法核验”。
3. 页面不可访问时，不要用搜索摘要或主观判断补写细节。提示用户可直接粘贴正文、推文内容、截图 OCR 文本或自己的描述。
4. 用户直接粘贴文字时，将其作为“用户提供材料”分析；保留可见事实，缺失字段写“未提供”，不要声称已核验原文。
5. 若用户同时提供链接和正文，以正文为主要分析依据，以链接作为来源线索；若两者冲突，标注冲突点。

## 固定输出版式

每次“读创意”都按以下结构输出。保持可读、具体、可迁移，避免空泛形容词。

### 基础信息

- 标题：用案例原题；无标题时生成一个准确标题
- 品牌：未提供则写“未提供”
- 来源：链接域名、平台名或“用户粘贴文本”
- 日期：原文可见日期；不可见则写“未提供 / 无法核验”
- 原文链接：有则保留；没有则写“无”
- 核验状态：已核验 / 部分核验 / 需要登录 / 无法核验 / 用户提供文本

### 创意洞察

说明这条创意抓住了什么情绪、场景、人群或文化趋势。必须回答“为什么这个洞察成立”。

可观察维度：

- 情绪：焦虑、怀旧、松弛感、陪伴、仪式感、反差、孤独、表达欲、社交货币
- 场景：节日、通勤、职场、校园、家庭、旅行、运动、音乐节、城市街头、社交平台
- 人群：年轻人、女性用户、亲子家庭、运动人群、职场人、粉丝社群、亚文化圈层
- 文化趋势：梗文化、复古回潮、疗愈经济、低成本快乐、户外生活、AI 话题、二创传播

### 创意内容

说明它具体讲了什么故事、主张、符号或信息。不要只写“有趣”“高级”，要指出内容构成。

包括：

- 核心信息：品牌想让用户记住什么
- 叙事方式：故事、反转、对话、清单、挑战、教程、测试、纪录、伪新闻、用户投稿
- 视觉/文案符号：节日符号、产品特征、人物、道具、场景、口号、梗、声音、包装

### 创意形式

归纳它用了什么媒介与执行形式，并说明形式为什么适合这条创意。

常见形式：

- 海报、短片、TVC、Reels/TikTok/B站视频、户外、快闪、橱窗、包装、礼盒、联名、互动装置、小游戏、UGC 挑战、直播、品牌事件、音乐节赞助、社群活动、小程序、AR/滤镜

### 可复用方法

把案例抽象成 2–5 条可迁移的方法，写成广告人做 brief 时能直接借鉴的动作。

示例写法：

- 把节日符号转译成产品造型，而不是只做节日配色
- 用用户吐槽反推文案，让品牌站到消费者一边
- 把线下装置设计成“必须拍照”的社交货币
- 把单品功能拆成多种人格/场景，让货架卖点变成内容资产

### 适用节点

列出适合沉淀的节点标签。没有明确节点时，写“日常传播”。

候选标签包括但不限于：圣诞节、春节、元宵节、情人节、妇女节、毕业季、开学季、夏日、七夕、中秋、国庆、万圣节、双11、黑五、世界杯、奥运、品牌周年、上新季、音乐节、露营季、返校季。

### 内容方向

列出 2–5 个内容向标签，用于未来检索。

候选标签包括但不限于：陪伴、反差、怀旧、松弛感、仪式感、社交货币、自我表达、治愈、幽默、吐槽、猎奇、公益、地域文化、圈层认同、粉丝共创、身份表达、情绪价值、功能利益、生活方式。

### 形式方向

列出 2–5 个形式向标签，用于未来检索。

候选标签包括但不限于：节日限定、产品拟人、场景装置、用户共创、梗图化表达、反转短片、互动包装、联名周边、线下快闪、户外大牌、橱窗陈列、AR 滤镜、小游戏、UGC 挑战、明星共创、产品海报、礼盒设计、声音营销。

### 视觉方向

列出 2–5 个视觉向标签，用于未来检索视觉参考。

候选标签包括但不限于：手绘插画、童趣涂鸦、复古拼贴、高饱和色彩、低饱和治愈、极简排版、字体设计、产品静物、人物摄影、包装主视觉、橱窗视觉、社媒模板、海报构图、材质肌理、AI 视觉、像素风、水彩感、胶片感。

### 标签

输出 6–12 个标签，覆盖品牌、行业、媒介、风格、人群和关键节点。不要重复主分类词；优先使用能帮助未来检索的词。

## 入库结构

当用户要求收藏或保存时，将读创意结果整理成以下字段，追加到 `ad-inspiration-library.json`：

```json
{
  "id": "YYYYMMDD-source-title-slug",
  "title": "",
  "brand": "",
  "source": "",
  "url": "",
  "date": "",
  "verification_status": "",
  "summary": "",
  "creative_insight": "",
  "creative_content": "",
  "creative_format": "",
  "reusable_methods": [],
  "occasions": [],
  "content_directions": [],
  "format_directions": [],
  "visual_directions": [],
  "tags": [],
  "user_note": "",
  "created_at": ""
}
```

若本地已有相同 URL 或相同标题+品牌+日期，更新原条目并保留用户备注，不要重复追加。

## 灵感库页面组织

灵感库不是单纯上传入口。它必须统一展示两类内容：

- 每日抓取页中用户收藏的案例；
- 用户手动上传链接、粘贴正文、粘贴推文或截图 OCR 文本后形成的案例。

灵感库页面必须提供：

- 上传链接输入框；
- 粘贴文字/推文/图片描述输入区；
- “AI 读创意”动作；
- “保存进灵感库”动作；
- 按节点向、内容向、形式向、视觉向的聚合区；
- 可搜索的案例卡片列表。

四大聚合区定义：

- 节点向：圣诞节、春节、情人节、开学季、夏日、音乐节、品牌周年等时间或场景节点；
- 内容向：情绪价值、社交货币、反差、怀旧、松弛感、陪伴、圈层认同、文化梗、可复用创意方法；
- 形式向：海报、短片、TVC、包装、礼盒、联名周边、快闪、装置、户外、橱窗、小游戏、UGC 挑战、AR 滤镜；
- 视觉向：色彩、画风、构图、字体、插画、摄影、包装视觉、海报风格、材质肌理、社媒视觉模板等视觉表达。
